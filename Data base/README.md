# Sistema de Perfil Financiero con IA

## Descripción

Sistema de base de datos diseñado para analizar el comportamiento financiero de usuarios mediante técnicas de Data Science e Inteligencia Artificial.

El sistema almacena movimientos financieros, información crediticia, metas de ahorro y resultados generados por modelos de Machine Learning para determinar perfiles financieros.

---

# Objetivo del proyecto

Crear una plataforma capaz de analizar hábitos financieros y clasificar usuarios según su comportamiento económico:

- Saludable
- En observación
- Riesgo financiero

mediante modelos de Inteligencia Artificial.

---

# Arquitectura de Base de Datos

La base de datos está diseñada aplicando principios de normalización hasta tercera forma normal (3FN).

Principales entidades:

- Usuarios
- Ciudades
- Cuentas bancarias
- Tarjetas
- Transacciones
- Categorías
- Historial crediticio
- Planes de ahorro
- Modelos IA
- Análisis financiero

# Instalación

- MySQL 8.0 o superior
- MySQL Workbench

2. Ejecutar el archivo:

3. Verificar la creación de las tablas.

# Modelo de Inteligencia Artificial

El sistema está preparado para integrar modelos como:

- Random Forest
- XGBoost
- Logistic Regression

La IA utiliza información como:

- Historial de movimientos
- Patrones de gasto
- Capacidad de ahorro
- Uso de crédito
- Comportamiento financiero
